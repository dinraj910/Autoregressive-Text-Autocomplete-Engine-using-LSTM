# Data Directory

This directory is intentionally empty.

The WikiText-2 dataset is loaded dynamically from HuggingFace in the training notebook.

No local data files are required.

## Dataset Information

- **Name**: WikiText-2 Raw
- **Source**: HuggingFace Datasets
- **Size**: ~2M tokens
- **Loading**: `datasets.load_dataset('wikitext', 'wikitext-2-raw-v1')`
