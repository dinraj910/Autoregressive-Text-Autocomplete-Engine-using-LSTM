# Models Directory

This directory contains the trained model files:

1. **autocomplete_lstm.h5** - Trained Keras model with weights
2. **tokenizer.pkl** - Fitted tokenizer for text preprocessing  
3. **config.json** - Model configuration

## How to Get These Files

1. Open `notebooks/training_lstm_colab.ipynb` in Google Colab
2. Enable GPU: Runtime → Change runtime type → GPU
3. Run all cells
4. Download the generated `model_files.zip`
5. Extract and place files here

## File Sizes (Approximate)

- autocomplete_lstm.h5: ~50-100 MB
- tokenizer.pkl: ~2-5 MB
- config.json: <1 KB
